# Arsim: playtest builds

Early playtest builds of Arsim, a co-op physics FPS for 1 to 4 players.

**Download:** go to the [Releases](../../releases/latest) page and download `ProjectArsim-Windows.zip`.

## How to play (Windows, 64-bit)

1. Unzip the whole file. Don't run the game from inside the zip.
2. Run `ProjectArsim.exe`.
3. For co-op, Steam must be running and logged in.

Windows SmartScreen may warn about an unknown publisher, because the build isn't code-signed. Click **More info**, then **Run anyway**.

This is an early development build, so expect bugs.
